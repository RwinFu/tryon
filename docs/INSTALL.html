OPTIC ARVIN · VIRTUAL TRY-ON · v2.0

نصب افزونهٔ پرو مجازی عینک روی سایت فروشگاه

یک فایل JS، یک <div>. پردازش کامل روی گوشی/سیستم مشتری انجام می‌شود؛ سرور شما هیچ تصویری دریافت نمی‌کند. برای Shopify، WooCommerce و هر سایت دیگری.

فایل‌ها تگ اسکریپت Shopify WooCommerce API products.json فریم جدید عیب‌یابی

۰۱فایل‌هایی که لازم دارید

dist/tryon.js

خودِ افزونه. تک‌فایل، بدون npm، بدون build سمت شما. حدود ۲۳۸KB gzip.

products.json

کاتالوگ فریم‌ها: نام، قیمت، رنگ‌ها، سایز چاپی، شکل فریم.

lib/

مدل تشخیص چهره و wasm. اگر میزبانی نکنید، افزونه از CDN می‌گیرد.

assets/frames/*.glb

اختیاری — مدل سه‌بعدی آماده برای صفحهٔ محصول و AR آیفون.

صفحه باید روی HTTPS باشد (یا localhost)؛ وگرنه مرورگر دوربین را باز نمی‌کند.

۰۲بدون کدنویسی: فقط attribute

فایل‌ها را در سایت کپی کنید، این سه تکه را جای‌گذاری کنید. تمام.

<!-- ۱) در <head> یا قبل از </body> -->
<script src="/tryon/dist/tryon.js"
        data-tryon-products="/tryon/products.json"
        data-tryon-lang="fa"
        data-tryon-accent="#d8b478"
        data-tryon-whatsapp="989190051635" defer></script>

<!-- ۲) روی صفحهٔ محصول: پرو داخل صفحه -->
<div data-tryon data-tryon-mode="inline" data-tryon-sku="AR-104" style="height:620px"></div>

<!-- ۳) هر جای دیگر: دکمهٔ پرو تمام‌صفحه -->
<button data-tryon-open data-tryon-sku="AR-104">پرو مجازی این مدل</button>

attributeهایی که افزونه می‌فهمد

attribute کار
data-tryon حضورش کافی است؛ همان‌جا نصب می‌شود.
data-tryon-mode inline داخل المان · overlay پنل کشویی · fullscreen
data-tryon-products URL به JSON کاتالوگ، یا فهرست SKU جداشده با کاما.
data-tryon-sku شناسه یا SKU محصول؛ اگر SKU متعلق به یک رنگ/واریانت باشد، همان رنگ نیز شروع می‌شود.
data-tryon-lang / -theme fa \| en — و auto \| light \| dark.
data-tryon-accent / -brand / -whatsapp رنگ، نام فروشگاه روی واترمارک، شماره واتساپ برای «افزودن به سبد».
data-tryon-cart event (به سبد خودتان) · whatsapp · link
data-tryon-config هر تنظیم دیگری به‌صورت JSON (همان options مربوط به init).

سازگاری با استایل سایت شما

افزونه داخل Shadow DOM است، پس CSS شما روی آن اثر ندارد و استایلش هم به سایت شما نشتی ندارد. برای شخصی‌سازی، متغیرها و partها را بفرستید: 

virtual-tryon {
  --vt-accent: #c9a24a;  --vt-radius: 18px;  --vt-font: "IRANSans", Tahoma, sans-serif;
}
virtual-tryon::part(stage) { background: #fff; }

۰۳Shopify

الف) یک Section در تم (پیشنهادی)

فایل sections/tryon.liquid را بسازید؛ بعد از آن در Edit Theme می‌توانید بلوک «پرو مجازی عینک» را به قالب محصول اضافه کنید.

{% style %} #Tryon-{{ section.id }} { height: {{ section.height }}px; } {% endstyle %}
<div id="Tryon-{{ section.id }}" data-tryon data-tryon-mode="inline"
     data-tryon-sku="{{ product.selected_or_first_available_variant.sku }}"></div>

ب) کاتالوگ از خودِ محصولات (بدون JSON دستی)

برای هر محصول یک metafield از نوع JSON با کلید custom.tryon_frame: { "shape": "cateye", "size": "53-19-145", "material": "acetate" }. رنگ‌ها و سایزها را افزونه از options محصول می‌خواند؛ اسم رنگ («مشکی براق»، «Havana Tan») را خودش به رنگ متریال تبدیل می‌کند و available=false را «ناموجود» می‌زند. 

window.TryOn.init({
  mount: "#tryon",
  products: [TryOn.fromShopify({{ product | json }}, {{ product.metafields.custom.tryon_frame.value | json }})],
});

ج) مدل سه‌بعدی محصول

با npm run bake برای هر مدل یک .glb می‌سازید؛ همان را در Shopify به‌عنوان 3D Model آپلود کنید تا مشتری آیفونی بتواند عینک را در اتاقش (AR Quick Look) ببیند. اگر ترجیح می‌دهید افزونه همان GLB را روی صورت بنشاند، در JSON محصول کلید glb و widthMM را بگذارید.

۰۴WooCommerce

یک فایل PHP در wp-content/plugins/tryon/tryon.php — enqueue + شورت‌کد + فیلد محصول:

<?php
/* Plugin Name: پرو مجازی عینک */
add_action('wp_enqueue_scripts', function () {
  wp_enqueue_script('tryon', content_url('/tryon/tryon.js'), [], null, true);
  wp_add_inline_script('tryon', 'window.__TRYON__ = ' . wp_json_encode([
    'products' => content_url('/tryon/products.json'),
    'brand'    => [ 'name' => get_bloginfo('name'), 'whatsapp' => get_option('tryon_whatsapp') ],
  ]) . ';', 'before');
});
add_shortcode('tryon', function ($a) {
  return '<div data-tryon data-tryon-mode="inline" data-tryon-sku="'
       . esc_attr($a['sku'] ?? '') . '" style="height:620px"></div>';
});

در صفحهٔ محصول: [tryon sku="AR-104"]. برای دادهٔ سه‌بعدی هر محصول هم می‌توانید متای _tryon_frame (JSON) بگذارید؛ TryOn.fromWoo(product, meta) همان را می‌خواند.

۰۵API — هر سایت دیگری

const tryon = TryOn.init({
  mount: "#tryon",              mode: "inline",
  products: "/tryon/products.json",
  brand: { name: "اپتیک آروین", accent: "#d8b478", whatsapp: "989190051635" },
  cart: { mode: "event", add: (item) => cart.add(item) },
  features: { hairLayer: true, contactShadow: true, fitSheet: true },
});

tryon.on("tryon:cart", (e) => cart.add({ sku: e.detail.sku, variant: e.detail.variant }));
tryon.on("tryon:fit",  (e) => console.log(e.detail.pd, e.detail.faceW));

tryon.select("AR-104");   // عوض کردن فریم
tryon.setVariant(1);      // عوض کردن رنگ
tryon.screenshot();       // عکس پرو با واترمارک فروشگاه
tryon.measurements();      // { pd, faceW, faceH, nose } به میلی‌متر
tryon.fitScore();          // { score, level, summary }
tryon.destroy();           // بستن دوربین و حذف کامل

رویدادها: ready · product · variant · fit · faceshape · snapshot · cart · log · error.

۰۷فریم جدید بدون مدل‌سازی سه‌بعدی

لازم نیست هر محصول را در Blender بسازید. در استودیوی فریم عکس تمام‌جبههٔ فریم را بکشید و عدد چاپی روی دسته را وارد کنید: لبهٔ عدسی‌ها اندازه‌گیری می‌شود، فریم با میلی‌مترهای واقعی ساخته می‌شود، و خروجی GLB + PNG + JSON همان لحظه قابل گرفتن است.

۰۸عیب‌یابی

نشانه علت و راه
دوربین باز نمی‌شود صفحه HTTP است → HTTPS. یا کاربر اجازه نداده → پیام خود افزونه را ببینید. در iframe باید allow="camera" باشد.
صفحه سفید/خطای Failed to fetch مسیر products.json یا lib/ غلط است؛ baseURL را در init بدهید.
عینک بزرگ/کوچک است عدد size محصول را از چاپ روی دسته بردارید؛ اگر نیست فاصلهٔ مردمک را دستی در برگهٔ فیت وارد کنید.
کند است quality: "lite" یا features: { hairLayer:false, contactShadow:false }.
استایل افزونه با تم شما نمی‌خواند theme: "light" یا متغیرهای --vt-accent و --vt-surface.
نسخهٔ افزونه ۲٫۰ — هندسهٔ فریم رویه‌ای با میلی‌متر واقعی · تشخیص چهره با MediaPipe Face Landmarker · رندر با three.js. هیچ تصویری از مشتری از دستگاه خارج نمی‌شود.

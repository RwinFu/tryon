# اصلاح واقع‌گرایی و گزارش تست — ۲۰۲۶/۰۹/۲۹

## علت‌ها و اصلاحات

- **عدسی شیری/غیرطبیعی:** ویدیوی DOM در بافر انتقال نور WebGL وجود نداشت. حالا همان تصویر دوربین/عکس با فضای رنگ sRGB (همراه سایه) پس‌زمینهٔ پاس انتقال نور است. عدسی شفاف دوباره tone-map نمی‌شود؛ بازتاب اضافی clearcoat حذف شده، ضخامت و زبری کاهش یافته‌اند. حالت lite شفافیت/تیرگی عدسی را حفظ می‌کند.
- **سطح عدسی:** بادبزن مثلثی با جهت اشتباه به سطح کروی حلقه‌بندی‌شده و نرمال/جهت درست تبدیل شد.
- **قرارگیری:** تصحیح کوتاه‌شدن فاصلهٔ چشم‌ها هنگام yaw، جابه‌جایی فاصلهٔ عدسی در امتداد نرمال صورت، لنگر گوشه‌های چشم به‌جای مردمک متحرک، نرمال‌سازی ماتریس چرخش، و رفع اشتباه yaw/roll. نمونه‌گیری PD خودکار هنگام پلک یا چرخش زیاد انجام نمی‌شود.
- **پرش و اتصال دوباره:** چند فریمِ تشخیص ازدست‌رفته باعث چشمک‌زدن مدل نمی‌شوند؛ بعد از ۷ تشخیص ناموفق مدل پنهان می‌شود. فیلترها برای تصویر/جلسهٔ جدید پاک می‌شوند.
- **پرو با عکس:** تغییر صریح IMAGE/VIDEO در MediaPipe، توقف حلقهٔ زنده حین پردازش، نمایش همان تصویر resize‌شدهٔ تشخیص، حفظ جهت اصلی عکس، خاموش‌شدن دوربین، بازگشت به دوربین، تعویض مدل/رنگ، PD دستی، برگهٔ فیت و ذخیرهٔ خروجی.
- **عکس محصول:** کلید کش شامل مسیرهای واقعی چپ/راست و کنترل‌های هندسه است؛ مسیرها در نرمال‌سازی کاتالوگ حفظ می‌شوند. اندیس اعشاری جست‌وجوی پل رفع شد. دکمهٔ مستقیم «پرو همین فریم روی صورت» به استودیو اضافه شد.
- **سایه:** تابع تعریف‌نشدهٔ `frontStroke` که رندر را می‌شکست حذف و فیلتر بر اساس نام قطعه اضافه شد. شدت/جابجایی سایه کمتر شد؛ دسته‌های پشت سر سایهٔ کاذب روی گونه نمی‌اندازند.
- **GLB:** تبدیل واحد روی زیرگروه حفظ می‌شود تا pose مقیاس میلی‌متری را پاک نکند. صفحهٔ جلوی مدل مرجع عمق است. رنگ‌کردن فریم، عدسی اصلی فروشنده را ۴۰٪ مات نمی‌کند. پاسخ دانلود قدیمی نمی‌تواند مدل تازه را جایگزین کند؛ منابع کنارگذاشته‌شده آزاد می‌شوند.
- **منابع و ابزارها:** dispose متریال فعلی پس از تعویض رنگ اصلاح شد. esbuild و sharp به نسخه‌های بدون آسیب‌پذیری گزارش‌شده در audit این اجرا ارتقا یافتند؛ ابزارهای توسعه اکنون Node.js 20.9+ می‌خواهند. Playwright به وابستگی‌های توسعه اضافه شد.

## بازنگری هندسه و کاتالوگ (۲۰۲۶/۰۹/۲۹)

- رینگ استات به یک حلقهٔ بستهٔ bevelدار تبدیل شد؛ جهت offset مثبت/منفی با تست contour کنترل می‌شود. شکل Wayfarer اختصاصی اضافه شد و همهٔ شکل‌دهنده‌ها پس از تغییر سیلوئت به اندازهٔ چاپیِ عدسی نرمال می‌شوند.
- پل فلزی، دستهٔ فلزی/استاتیِ ترکیبی، endpiece و mountهای rimless از هم تفکیک شدند؛ `AR-123` نمونهٔ ترکیبیِ آزموده‌شده است.
- کاتالوگ با ۲۸ رکورد مدل‌های نام‌دار و پیوندهای سازنده/فروشنده بازسازی شد. ارتفاع‌های عدسی‌ای که منبع منتشر نمی‌کند با `lensHSource: "estimated"` مشخص‌اند؛ Chrome Hearts فقط به منبع فروشنده تکیه دارد.
- **مدل سه‌بعدی رسمی SKUها موجود نیست.** پیش‌نمایش‌ها برچسب `procedural-preview` دارند و با مش رسمی/اسکن اشتباه گرفته نمی‌شوند. جزئیات کامل: [REAL-MODELS.md](REAL-MODELS.md).

### پوشش مجموعهٔ مرورگر (۶ سناریو؛ در این اجرای جاری اجرا نشد)

1. WebGL: عبور رنگ از عدسی، سایه و آزادشدن تکسچر هنگام تغییر اندازه.
2. **مدل MediaPipe واقعی** روی عکس نمونه: آپلود ۲۰۴۸px، تغییر رنگ/مدل، حالت بدون چهره، PD دستی، گزارش فیت، snapshot و انتقال به ویدیو.
3. استودیو: عکس محصول، اندازه‌گیری، پیش‌نمایش، پرو مستقیم و خروجی تخت.
4. نشست اسکن چهرهٔ واقعی: گزارش، مش سه‌بعدی و GLB.
5. رابط اسکن: landmarks واقعی، مراحل، جدول، پیش‌نمایش و GLB.
6. بارگذاری دیررس GLB: پاسخ مدل قدیمی نباید مدل تازه را عوض کند و مقیاس ۱۴۰mm باید حفظ شود.

`npm run test:browser` در این اجرا پیش از اجرای سناریوها متوقف شد: Chromium محلی موجود نبود، دانلود رسمی Playwright با خطای TLS `ECONNRESET` شکست خورد، و بستهٔ موقت Chromium در این سیستم به کتابخانه‌های `libnspr4` و `libnss3` دسترسی نداشت. برای تست ویدیو از `canvas.captureStream()` استفاده می‌شود؛ **دوربین فیزیکی، حرکت واقعی سر، Safari/iOS و نورپردازی‌های مختلف همچنان نیاز به ارزیابی انسانی دارند**. تست‌های ریاضی زوایای مصنوعی را پوشش می‌دهند، نه تأیید دقت بالینی یا کیفیت روی همهٔ چهره‌ها.

## اجرای دوباره

```bash
npm ci
npm run build
npm test
npx playwright install --with-deps chromium
npm run test:browser
npm audit
```

برای Chromium نصب‌شدهٔ سیستم، مسیر باینری را با `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` بدهید.
خروجی‌ها و اسکرین‌شات خطا در `.cache/browser-results/` هستند و وارد Git نمی‌شوند.
در تلاش جایگزین، بستهٔ `@sparticuz/chromium@143.0.4` موقتاً در محیط نصب شد اما به‌علت نبودن
`libnspr4` و `libnss3` شروع نشد؛ این بسته به `package.json` اضافه نشده و وابستگی زمان اجرای فروشگاه نیست.

## مرز دقت

تک‌عکس محصول اطلاعات کافی برای بازسازی کامل سه‌بعدی دسته و بافت ندارد؛ خطوط عدسی استخراج و باقی مدل تخمین زده می‌شود.
پوشانندگی سر همچنان تقریبی است. PD وابسته به قطر فرضی عنبیه و دوربین است؛ برای سنجش اپتیکی نسخهٔ واقعی استفاده شود.
پیش از انتشار فروشگاهی، روی چند گوشی و چهره، چرخش ±۳۰ درجه، پلک‌زدن، مو، نور کم/زیاد و قطع/وصل اجازهٔ دوربین بررسی انسانی انجام شود.

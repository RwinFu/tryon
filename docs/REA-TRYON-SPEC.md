# مشخصات clean-room تجربهٔ پرو محصول

## نیازمندی‌ها

1. دکمهٔ پرو هر کارت باید همان SKU و رنگ انتخاب‌شده را به نمای دوربین ببرد.
2. کنترل «داخل / بیرون» باید بدون خاموش‌کردن دوربین ظاهر عدسی را عوض کند.
3. برای عینک طبی، داخل = عدسی شفاف و بیرون = شبیه‌سازی عدسی فتوکرومیک خاکستری.
4. برای عینک آفتابی، بیرون باید عدسی اصلی محصول را حفظ کند و داخل نسخهٔ روشن‌تری نشان دهد.
5. کنترل +/− باید اندازهٔ بصری فریم را در محدودهٔ امن تغییر دهد و نقطهٔ اتصال روی بینی ثابت بماند.
6. تغییر محصول یا رنگ باید حالت عدسی جاری را روی محصول جدید اعمال کند.
7. کنترل‌ها باید با لمس، صفحه‌کلید، RTL/LTR، safe-area و صفحهٔ باریک کار کنند.
8. وضعیت انتخاب‌شده باید با `aria-pressed` اعلام شود.

## خطاها و لبه‌ها

- نبود WebGL یا فریم: کنترل نباید برنامه را خراب کند.
- محصول بدون مشخصات عدسی: از `clear` و شبیه‌سازی بیرونی استاندارد استفاده شود.
- زوم بیش از حد: در بازهٔ 0.86 تا 1.18 محدود شود.
- تغییر سریع محصول/رنگ: آخرین انتخاب باید برنده باشد.

## آزمون پذیرش

- انتخاب بیرون، متریال عدسی را عوض می‌کند و انتخاب داخل آن را بازمی‌گرداند.
- سه بار + از سقف عبور نمی‌کند؛ سه بار − از کف عبور نمی‌کند.
- انتخاب variant پس از تغییر حالت نور، همان حالت نور را نگه می‌دارد.
- دکمه‌ها نام قابل‌دسترسی و حالت `aria-pressed` صحیح دارند.
